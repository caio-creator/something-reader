# ReadMaxx product teardown

Public sources: [readmaxx.app](https://readmaxx.app), [App Store](https://apps.apple.com/br/app/readmaxx/id6757965441), Instagram `@readmaxx.app`, X `@ReadMaxx_`. Crossed with local screenshots in `references/readmaxx/` (not shipped).

Developer: MAXX TECHNOLOGIES LIMITED (Dominic Norton). Also ships PaperTrail (book tracker). Current store version observed: **1.22.0** (camera document scan). Screenshots in the zip are **1.15.0**.

## Positioning

“A new way to read.” RSVP as the product. Formats are fuel. Claim: faster reading “with science,” better retention. iPhone + iPad. Not a desktop app (Mac listing is Designed for iPad). iOS 18+.

## Feature map

| Feature | Class | Notes |
|---|---|---|
| Paste / URL / EPUB / PDF import | ESSENTIAL | The wedge. Keep. |
| Sample document | ESSENTIAL | Kills empty-state fear. Keep. |
| RSVP with ORP alignment | ESSENTIAL | Keep as a mode. Own the accent. |
| WPM / PPM control | ESSENTIAL | Keep. Default ~300 is aggressive; default lower. |
| Sentence-end dwell | ESSENTIAL | Timing, not a gimmick. Keep. |
| Resume position | ESSENTIAL | Store once lied; they patched it. Sacred. |
| Content Explorer | IMPROVE | They added it because RSVP-only fails. We invert: traditional first. |
| Library with progress / finished | ESSENTIAL | Keep simple. Call it Things. |
| Live appearance preview | KEEP | Good. |
| Fonts including OpenDyslexic | KEEP | Accessibility with evidence-ish community use. |
| ORP color | OPTIONAL | Nice, not identity. Don’t default to their red. |
| Gradient backgrounds | OPTIONAL | Pretty, easy to get tacky. One quiet option max. |
| Haptics (word / sentence) | OPTIONAL | iOS-only. Skip web MVP. |
| AI summaries + “Resumir” tab | NOT NOW | Second product. Needs model/API. Their paywall neighbor. |
| Chapter-end recap | NOT NOW | Same. |
| Camera OCR | FUTURE | They just shipped it. We wait. |
| Share-sheet import | V1 | Desktop equivalent is drag-drop / open with. |
| “3× with science” | AVOID | Contradicted by reading science (see speed-reading-research.md). |
| Unlimited IAP on large files | AVOID | The reason this project exists. |
| Tracking (purchases, IDs, usage) | AVOID | Privacy opposite. |
| Red bookmark icon / wordmark | AVOID | Trade dress. |

## Monetization

Free app, IAP **Unlimited** weekly R$ 19,90 and monthly R$ 19,90 / 29,90. Large PDF/EPUB behind the paywall is the user’s actual pain. Privacy nutrition label: tracking via purchases, identifiers, usage.

## What they do well

Friction from file to first word is low. ORP is taught in onboarding, not hidden in settings. Explorer exists as an escape hatch. Appearance is considered. iPad layout uses the canvas.

## What they do badly

Science copy. Paywall on the core job. Performance on long books (App Store: “laggy” on 15 Pro Max). Traditional reading is a sheet, not a reader. No real Mac/desktop. Tracking. AI summaries compete with the reader for attention.

## Opportunities for Something

1. Desktop + unlimited local files.
2. Traditional reader as the default surface; RSVP as Focus.
3. Honest copy.
4. Local-first, no account, no telemetry in core.
5. Open source.
6. Progress that does not vanish.
7. Typography as product, not a settings graveyard.
