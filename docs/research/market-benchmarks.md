# Market benchmarks

Something sits at the intersection of **document reader**, **speed/focus reading**, and **read-it-later**. The empty cell is: local files (especially large PDF/EPUB), two reading modes, resume, desktop, no account.

Commodity: import EPUB, dark mode, font size, a library list. Gimmicks: miracle WPM, haptic reading, AI recap as the homepage. Still unsolved: good PDF-to-text, honest RSVP, local-first desktop without becoming Calibre.

## Patterns to steal (not copy)

- One import surface, then read (ReadMaxx).
- Resume is a promise, not a setting (every good reader).
- Typography controls with live preview (ReadMaxx, Apple Books, Foliate).
- Progress as a first-class library field (ReadMaxx 1.16 sections: new / reading / finished).
- Escape hatch from RSVP to real text (ReadMaxx Explorer).

## Patterns to refuse

- Paywall on file size.
- “Science” as advertising.
- AI tab competing with Read.
- Knowledge-graph as v1 (Readwise).
- Calibre-level preference explosion.
- Cloud as a precondition.

## Differentiation

Something is not the best research manager, not the best TTS, not the best store. It is the shortest path from **a file on disk** to **a reading session that still exists tomorrow**, on a computer, with an optional focus mode that does not lie about comprehension.
