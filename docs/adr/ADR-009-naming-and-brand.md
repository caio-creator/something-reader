# ADR-009 — Naming and brand

- Status: accepted
- Date: 2026-09-04

## Decision

Brand **Something**. Descriptor **Something Reader**. Wordmark `something.`. Tagline “Read something.”

Rejected as product names: Octavo (fine but not a brand system), Read this shit (campaign only), GitHub `something` (too generic).

Trademark clearance (INPI/USPTO) is required before App Store / paid domain, not before the local MVP.
