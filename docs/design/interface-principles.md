# Interface principles

- One primary action per view.
- Typography is the product.
- Desktop gets a sidebar and keyboard. Mobile gets a single column. Do not stretch a phone UI.
- Empty states speak the lexicon (Nothing / Something).
- Quiet motion. Honor `prefers-reduced-motion`.
- Contrast over atmosphere. Gradient is optional, never default.
- Do not look like ReadMaxx. No red bookmark, no red ORP default, no science onboarding.
