# Apple HIG applied on the web

Something is a web app. We do not ship Apple's Liquid Glass API. We apply HIG *principles*.

## Principles used

- **Clarity** - one primary action, large titles, 17pt list rows
- **Deference** - chrome recedes; the page is the product
- **Depth** - hairline separators, grouped surfaces, blur only on toolbar and Focus dock
- **Semantic color** - system blue for action, system red for remove, labels in four opacities
- **Dynamic Type-ish** - S/M/L reading sizes
- **44pt** tap targets on primary controls
- **Segmented control** for Read / Focus
- **Grouped lists** for Things
- **System fonts** - SF stack for UI, New York / Iowan for reading (Apple Books pairing)

## What we did not copy

Apple trademarks, SF as a webfont file, official Liquid Glass, iOS tab bars, the Books icon language.
