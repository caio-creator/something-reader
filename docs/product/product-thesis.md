# Product thesis

Something is a local-first reader for whatever you already have.

It exists so a book, PDF, paper, or pasted article can become a reading session that still exists tomorrow — on a computer, without an account, without a paywall.

Use it instead of Kindle when the file is yours. Instead of Readwise when you do not want a knowledge OS. Instead of ReadMaxx when the file is large, the machine is a desktop, or you refuse to rent your own documents.

Local-first means the bytes never need a server to be read. Open source means someone can clone it, audit it, and keep it when a hosted reader dies (Omnivore is the ghost at this feast).

Wedge: **Drop something. Read something. Close it. Open it. Continue.**

Not a summarizer. Not a Zotero. Not a speech app. Not “3× with science.”
